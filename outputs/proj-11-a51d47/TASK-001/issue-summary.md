## Requirement Summary

Build a minimalist single-page personal homepage that efficiently presents personal information, recent activity, and external links within one screen, without requiring navigation to other pages.

## Required Modules

1. Personal information area at the top or side:
   - High-resolution avatar.
   - Name or nickname.
   - One-line introduction, such as frontend developer / photography enthusiast.
   - Social link icons, such as GitHub, Zhihu, and email.
2. Main featured content area:
   - Recent activity with 3 to 5 latest article titles and short summaries.
   - Optional featured projects shown as 1 to 3 project cards.
3. Footer:
   - Simple copyright statement.
   - ICP filing number if needed.

## Interaction And Visual Requirements

1. Responsive layout:
   - Mobile uses vertical stacked layout.
   - Desktop may use left-right split or centered card-style layout.
2. Visual style:
   - Minimal and clean.
   - Text content should remain the primary focus.
3. Micro-interactions:
   - Links and cards should have subtle hover color changes or a slight upward motion.

## Technical Direction

Use a purely static implementation: HTML, CSS, and a small amount of JavaScript if needed.
