# 欢迎来到科幻博客

这是我的第一篇博客文章，带你探索科幻世界的边界。

## 特性

- **科幻风格设计**: 深色主题，霓虹配色
- **Markdown 支持**: 使用 marked.js 渲染
- **代码高亮**: highlight.js 提供语法高亮
- **AI 对话**: 内置 AI 助手交互界面

## 代码示例

```javascript
// 欢迎使用科幻博客
function hello() {
  console.log('Hello, Sci-Fi Blog!');
  return {
    theme: 'cyberpunk',
    status: 'online'
  };
}

hello();
```
