## Requirement Summary

Build a minimalist single-page personal homepage that presents personal information, recent updates, and external links within one screen without requiring navigation to other pages.

Core page areas:

- Personal info area at the top or side, including a high-resolution avatar, name or nickname, one-line bio, and social link icons such as GitHub, Zhihu, and email.
- Main featured content area, including 3 to 5 recent article entries with titles and short summaries.
- Optional featured projects area with 1 to 3 representative project cards.
- Footer with a concise copyright statement and optional ICP filing number.

Interaction and visual requirements:

- Responsive layout: stacked layout on mobile; two-column or centered-card layout on desktop.
- Minimal, clean visual style with text content as the focus.
- Micro-interactions for links and cards, such as subtle color changes or upward motion on hover.

Technical guidance:

- A pure static implementation is sufficient: HTML, CSS, and a small amount of JavaScript if needed.

## Acceptance Focus

- The delivered page should be usable as a standalone personal homepage.
- The first viewport should clearly show the person, recent writing, and external links.
- The layout should work on both mobile and desktop.
- Hover states should be visible but restrained.
- Implementation should avoid unnecessary framework or build complexity unless the repository already requires it.
