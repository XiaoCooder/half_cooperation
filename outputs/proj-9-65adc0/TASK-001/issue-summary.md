## Requirement Summary

Build a minimalist single-page personal homepage that presents personal identity, recent updates, selected work, and external contact links within one screen where possible. The page should avoid unnecessary navigation and emphasize concise text content.

## Core Page Modules

- Personal information area at the top or side.
  - High-quality avatar.
  - Name or nickname.
  - One-sentence profile, such as frontend developer / photography enthusiast.
  - Social link icons, such as GitHub, Zhihu, and email.
- Featured content area as the main page body.
  - Recent updates with 3 to 5 latest article titles and short summaries.
  - Optional selected projects with 1 to 3 representative project cards.
- Footer.
  - Simple copyright statement.
  - ICP filing number only if needed.

## Interaction and Visual Requirements

- Responsive layout.
  - Mobile: vertically stacked layout.
  - Desktop: left/right split layout or centered compact layout.
- Minimal, clean visual style with text content as the focus.
- Micro-interactions.
  - Links and cards should have subtle color changes or slight lift effects on hover.

## Suggested Technology

- Pure static page is sufficient.
- Use HTML, CSS, and a small amount of JavaScript if needed.
